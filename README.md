# course_project

基于 Quanser **QArm**（4 自由度机械臂）的大作业项目。（具体作业要求待补）

- 调研报告：[docs/research/qarm_survey_2026-10-22.md](docs/research/qarm_survey_2026-10-22.md)

## 目录结构

| 目录 | 用途 |
|---|---|
| `scripts/` | 代码与脚本 |
| `data/` | 数据（原始 / 处理后） |
| `results/` | 结果、图、模型等产物（按时间戳或序号分子目录，不覆盖） |
| `logs/` | 运行日志 |
| `docs/` | 作业要求、报告、参考资料 |
| `_backup/` | 不再使用但不删的数据/模型、>100MB 推不上 GitHub 的大文件（按 `<任务名>_<日期>/` 分子目录，不进 git） |
